概要
どんな作品
ゲーム依存症の知識と対処法を小学1〜3年生に伝えるパズル×ノベルゲーム。 ICD-11のゲーム障害の症状を形にした敵キャラと戦う物語を通じて、 「禁止」でなく「知識とスキル」で依存を予防するアプローチを採用。 Itch.io にてリリース済み。
担当領域
アシスタントディレクター兼プログラマー統括として、 フレームワーク層・ゲームUI層の設計・実装を担当。 汎用オブジェクトプール・Addressablesパイプライン・ CSV駆動ノベルシステム・シーン遷移フレームワーク・ UI Raycast Debugger を構築し、チーム全体の開発基盤を整備。
プロジェクトの特殊な状況
企画（ゲームメカニクス）がなかなか固まらなかったため、UIやゲームロジックを個別に進めることができず常に後手に回る状況だった。 その間、プログラマー3名で「どの企画になっても使える汎用基盤」を先行開発。 フレームワーク層 / ゲームロジック層 / ゲームUI層の3層に分け、層を跨ぐ際に疎結合で渡す設計を採用。 KISS原則・DRY原則を軸に、可読性・保守性・拡張性を担保した。

Script
① 汎用オブジェクトプール ─ ObjectPool.cs / APooledObject.cs
使う側は Get() / Release() の2行のみ。二度戻し防止・ライフサイクル通知・上限管理を基底クラスで一括担保。 
// 使う側：Shooter.cs
pool = new ObjectPool<piece>(pieceFactory, initial:3, max:12);
pool.Prewarm(); // 事前生成して非アクティブで積む
var b = pool.Get();    // 取り出す
// Bullet側で当たり判定後に
b.Release();          // 返す（二度戻し防止済み）

// 基底クラス：APooledObject.cs
public void Release() {
    if (_inPool) return; // 二度戻し防止
    _inPool = true;
    OnDespawn();
    _return?.Invoke(this);
}

// TextManager.cs：CommentNo を発行するだけ
OnCommentChanged?.Invoke(cno); // "CHAP1-5" を投げる

// CharacterManager.cs：CSVの1行で演出が全部決まる
StoryCueRepo.TryGet(commentNo, out var row);
BeginCrossFade(bg,   row.BgId,    dur, ref _xfBG);
BeginCrossFade(left, row.LeftId,  dur, ref _xfL);
BeginMulFade(_bgMat, PickMulColor(row.GrayBG, row.BlackBG), ...);

sound.PlaySE(row.SEId);
sound.PlayBGMAsync(row.BGMId, loop:true).Forget();
